**Cinematic AI Video Studio — Flutter UI foundation**

HOTICE is a premium multi-AI video creation workspace. This repository contains a **functional studio preview** with responsive navigation, local project planning, inspiration, account access through the shared backend, encrypted device persistence, and explicit per-project cloud copies. Actual provider video generation, live payments and publication-ready signed builds are not connected yet.

## Guided 2D face capture beta — feature branch (28 Oct 2026)

This branch adds a consented, **on-device front-camera scanner** with ML Kit face detection, head-angle guidance, front portrait open-eye checks, consecutive-frame auto-capture, still-image revalidation, and five reusable front/side photo references per Actor. Native camera permissions are generated by `tools/configure_face_capture.py` after `flutter create .`. Live scanner is available in Avatar Studio.

**Important:** This is not full 3D reconstruction, facial biometric verification, liveness proof or working AI-video avatar identity. Actor/reference metadata is stored in the encrypted device-local project archive; accepted face photos are separately encrypted in app-private Android/iOS storage with workspace-derived keys rooted in OS secure storage. This provides workspace separation on one device, not protection from device compromise. There is no cloud sync; user-managed encrypted actor backups are the only cross-device recovery path. Physical-device testing remains required. Read [Smart reference implementation and limitations](docs/SMART_REFERENCE_ENGINE.md).

## Run locally
Install the Flutter SDK, then in this repository:

~~~sh
flutter create . --project-name hotice --platforms=android,ios
python3 tools/configure_face_capture.py
flutter pub get
flutter run
~~~

The platform scaffolds (Android/iOS) are intentionally not committed at this UI-first phase; the command creates them. The GitHub Actions workflow also prepares them before analysis and tests.
