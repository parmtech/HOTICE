# HOTICE — Responsive studio UX audit (3 November 2026)

## Scope
Draft child of `fix/native-session-restore-resilience` (PR #59), itself on the unmerged native account/client stack. Changes intentionally affect only the Flutter studio presentation; they do not enable billing, video generation, uploads or automatic cloud sync.

## Issues corrected
- **Desktop window height:** the old fixed-height sidebar used a non-scrollable Column with a Spacer and could overflow at short heights or when accessibility text was enlarged. The navigation is now in a scrollable list so every destination remains reachable.
- **Compact phones and split-screen:** content gutters scale down on narrower viewports, improving usable editor width and text wrapping.
- **Project data transparency:** the old warning incorrectly asserted that all projects vanish after every restart. Native builds in this stack save bounded project text/storyboards in encrypted device storage; this is *not* a media archive or cloud backup. The notice now communicates the actual data-loss boundary.
- **Project grid responsiveness:** project card scene/storyboard totals are now aggregated once per build in O(drafts + storyboards + projects), avoiding an O(projects × (drafts + storyboards)) series of repeated filters.
